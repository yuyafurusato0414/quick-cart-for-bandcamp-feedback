# Quick Cart for Bandcamp — Bug reports

[Report a bug](https://docs.google.com/forms/d/e/1FAIpQLSdsyMJ8AvkXipRZgExJQ9VeoIY3EHtf088GyBoBJ-MerUEWRg/viewform)

No sign-in is needed. Tell us what went wrong; the other fields are optional. Reports are only visible to the developer. Please do not include passwords or card numbers.

Quick Cart for Bandcamp is an unofficial Chrome extension, not affiliated with Bandcamp.
