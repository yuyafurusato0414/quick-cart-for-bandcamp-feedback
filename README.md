# Quick Cart for Bandcamp — Bug reports

This is the public bug report tracker for Quick Cart for Bandcamp, an unofficial Chrome extension. It is not affiliated with Bandcamp.

[Report a bug](https://github.com/yuyafurusato0414/quick-cart-for-bandcamp-feedback/issues/new?template=bug_report.md)

Please describe how to reproduce the problem, what you expected, what happened, and your extension version, Chrome version and OS. Japanese and English reports are welcome.

Reports are public and require a GitHub account. Do not include personal information, payment details or private page URLs. Redact any screenshots before attaching them.
